# Colophon

Let's get into some technical details about my website. I've had this domain (jrb.nz) for a few years now, and the website has seen some radical changes over the years. This is the latest version's details.

## Templating

This website is made using a static site generator called [Eleventy](https://11ty.dev/). It's using a customized version of the [eleventy-base-blog](https://github.com/11ty/eleventy-base-blog).

All the content is written in markdown. The templating is done using nunjucks files.

## Typography

The main font used is [Bricolage Grotesque](https://ateliertriay.github.io/bricolage/) by [Mathieu Triay](https://www.mathieutriay.com/).

I'm also using [Atkinson Hyperlegible Next](https://fonts.google.com/specimen/Atkinson+Hyperlegible+Next) in some areas.

## Deployment & hosting

It is deployed and hosted on Cloudflare Pages. The source code is [publicly available on Github](https://github.com/jr-b/jrb.nz.v3).
